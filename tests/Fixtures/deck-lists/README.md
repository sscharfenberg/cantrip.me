# Deck list fixtures

Pasted deck lists for `DeckListParserTest`, one file per site and export mode.

**These are reconstructions, not captured exports.** They follow each site's export format as documented and commonly seen, but were written by hand on 2026-10-04. When a real export disagrees with one of them, replace the file with the real export and fix the parser — the files are the specification, so they should be the real thing.

| File | Source |
| --- | --- |
| `moxfield-bulk-edit.txt` | Moxfield → Bulk Edit (no commander, `*F*` finishes, `#tags`) |
| `moxfield-mtga.txt` | Moxfield → Export → Copy for MTGA |
| `archidekt-text.txt` | Archidekt → Export → text, with categories and labels |
| `draftsim.txt` | Draftsim deck copy (type headlines, no printings) |
| `mtga.txt` | MTG Arena export (`About` / `Commander` / `Deck` / `Sideboard`) |
| `mtgo.txt` | MTGO `.txt` (sideboard after a blank line, no headers) |
| `cantrip-print.txt` | cantrip.me `/decks/{deck}/print`, en — generated by `resources/app/utils/printableDeck.ts` |
| `cantrip-print-de.txt` | the same in German |
